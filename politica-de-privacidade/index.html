Política de Privacidade

Legendários Rota dos Marechais — Alagoas  ·  Última atualização: 15 de maio de 2026

1. Quem Somos

A Rota dos Marechais é a expressão alagoana do movimento Legendários, realizada em Arapiraca, Alagoas. Este documento descreve como tratamos dados pessoais em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD — Lei nº 13.709/2018).

Controlador dos dados: Legendários Rota dos Marechais
Contato: Instagram @legendariosrotadosmarechais

2. Dados Coletados

2.1 Navegação neste site

Este site não coleta dados pessoais diretamente nem utiliza formulários próprios. Ao navegar, seu navegador pode se conectar a serviços externos:

  • Google Fonts (fonts.googleapis.com) — carregamento de tipografia. A Google pode registrar seu endereço IP conforme sua Política de Privacidade.
  • Tailwind CSS CDN — biblioteca de estilos. Pode registrar requisições de acesso.

2.2 Inscrições no evento

As inscrições são processadas pela plataforma TicketAndGo (ticketandgo.com.br), um serviço terceiro independente. Os dados fornecidos no ato da inscrição — como nome, e-mail, telefone e dados de pagamento — são coletados e tratados exclusivamente pela TicketAndGo, sob sua própria política de privacidade.

Recomendamos a leitura da política de privacidade da TicketAndGo antes de concluir sua inscrição.

2.3 Cookies

Este site não utiliza cookies próprios para rastreamento ou publicidade. Serviços de terceiros (Google Fonts, Tailwind CDN) podem definir cookies técnicos de sessão em conformidade com suas respectivas políticas.

3. Finalidade do Tratamento

  • Disponibilizar informações sobre o evento Rota dos Marechais
  • Facilitar o acesso à plataforma de inscrição
  • Comunicar datas, valores e condições do evento

4. Base Legal (LGPD)

O tratamento de dados neste site se baseia no legítimo interesse (Art. 7º, IX da LGPD) para divulgação do evento, e no consentimento (Art. 7º, I) quando o usuário opta por se inscrever por meio da plataforma TicketAndGo.

5. Compartilhamento de Dados

Este site não coleta nem compartilha dados pessoais com terceiros de forma direta. A plataforma TicketAndGo é integralmente responsável pelo tratamento dos dados fornecidos no processo de inscrição.

6. Seus Direitos (LGPD)

Conforme os Arts. 17 a 22 da LGPD, você tem direito a:

  • Confirmação da existência de tratamento de dados
  • Acesso aos seus dados pessoais
  • Correção de dados incompletos, inexatos ou desatualizados
  • Anonimização, bloqueio ou eliminação de dados desnecessários
  • Portabilidade dos dados a outro fornecedor de serviço
  • Eliminação dos dados tratados com consentimento
  • Informação sobre compartilhamento com terceiros
  • Revogação do consentimento

Para exercer qualquer um desses direitos, entre em contato pelo Instagram: @legendariosrotadosmarechais

7. Retenção de Dados

Este site não armazena dados pessoais em servidores próprios. Os dados de inscrição ficam sob custódia da TicketAndGo pelo período necessário à execução do contrato e cumprimento de obrigações legais.

8. Segurança

Adotamos medidas técnicas e organizacionais adequadas para proteger as informações disponíveis neste site. O acesso é realizado via HTTPS (protocolo seguro). Contudo, nenhuma transmissão de dados pela internet é absolutamente segura.

9. Links Externos

Este site contém links para plataformas externas: TicketAndGo, Instagram e Legendários Brasil. Não nos responsabilizamos pelas práticas de privacidade adotadas por essas plataformas. Recomendamos a leitura das respectivas políticas de privacidade.

10. Transferência Internacional de Dados

O carregamento de fontes via Google Fonts pode envolver transferência de dados para servidores fora do Brasil. A Google LLC mantém adequação às normas internacionais de proteção de dados, incluindo o GDPR europeu e acordos de transferência compatíveis com a LGPD.

11. Alterações nesta Política

Esta política pode ser atualizada periodicamente para refletir mudanças nas práticas do site ou na legislação aplicável. A data de "última atualização" no topo deste documento indica quando a versão mais recente foi publicada. Recomendamos a revisão periódica desta página.

12. Contato

Para dúvidas, solicitações ou reclamações relacionadas a esta política ou ao tratamento de dados:

  • Instagram: @legendariosrotadosmarechais
  • Movimento Legendários Brasil: legendarios.org.br
